# AI-EA-Lab: Research & Experiment Planning History

This directory contains the permanent record of quantitative research hypotheses, experiment specifications, and research contexts generated by the **AI Researcher** and **Experiment Planner**.

```
research/
├── hypotheses/        # Structured research hypotheses (HYP-XXXX.json)
├── plans/             # Controlled experiment specifications (PLAN-XXXX.json)
├── context/           # Snapshots of the project research context
├── llm/               # LLM adapter interface (zero external dependencies)
└── README.md          # Research repository index and guidelines
```

## Governance & Boundaries

1. **Human Approval Boundary**: All experiment plans are generated with `status: "planned"` and require human review before any code modification or execution.
2. **Fact vs Hypothesis Distinction**: Observations and historical claims are strictly distinguished from inferences, hypotheses, and expected observations.
3. **No Fabrication**: Historical data is pulled directly from verified experiment archives. No data or metrics are ever fabricated.
4. **Controlled Testing**: Each experiment plan is referenced to a concrete baseline experiment (e.g. `EXP-0002`), testing ideally one primary independent variable at a time.
5. **No Profit Maximizer**: The system evaluates multi-dimensional trade-offs without computing simplistic ranking scores or designating "winner" strategies.
